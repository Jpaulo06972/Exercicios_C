# Estruturas de Dados e Recuperação I 📂

Este módulo engloba os conceitos iniciais e aplicações de **Estruturas de Dados Dinâmicas e Recursividade** em linguagem C, desenvolvidos na disciplina de **Estrutura e Recuperação de Dados I**.

---

## 📂 Estrutura de Conteúdo

```text
EstruturaRecuperacaoDados_1/
├── Aula1_Recursividade/       # Funções recursivas (Fatorial, Fibonacci, potenciação, percursos)
├── Aula2_ListasEncadeadas/    # Implementação de Lista Encadeada Simples
├── Aula3_Filas/              # Implementação de Fila Encadeada (FIFO)
├── Aulas4_Pilhas/            # Implementação de Pilha Encadeada (LIFO)
├── Calculadora/              # Aplicação de Pilha/Fila em Calculadora de Expressões
├── ParentesesBalanceados/    # Verificação de balanceamento de colchetes, chaves e parênteses
└── UndoRedo/                 # Simulação do mecanismo de Desfazer e Refazer (Undo/Redo)
```

---

## ⚡ Como Compilar e Executar (Copiar e Colar)

### 1. Aula 1 - Recursividade (`Aula1_Recursividade`)
```bash
cd EstruturaRecuperacaoDados_1/Aula1_Recursividade && gcc -Wall -Wextra Ex_1.c -o ex1 && ./ex1
```

### 2. Aula 2 - Listas Encadeadas (`Aula2_ListasEncadeadas`)
```bash
cd EstruturaRecuperacaoDados_1/Aula2_ListasEncadeadas && gcc -Wall -Wextra Ex.c -o ex && ./ex
```

### 3. Aula 3 - Filas (`Aula3_Filas`)
```bash
cd EstruturaRecuperacaoDados_1/Aula3_Filas && gcc -Wall -Wextra Ex.c -o ex && ./ex
```

### 4. Aula 4 - Pilhas (`Aulas4_Pilhas`)
```bash
cd EstruturaRecuperacaoDados_1/Aulas4_Pilhas && gcc -Wall -Wextra Ex.c -o ex && ./ex
```

### 5. Projeto Calculadora (`Calculadora`)
```bash
cd EstruturaRecuperacaoDados_1/Calculadora && gcc -Wall -Wextra Ex.c -o calc && ./calc
```

### 6. Projeto Parênteses Balanceados (`ParentesesBalanceados`)
```bash
cd EstruturaRecuperacaoDados_1/ParentesesBalanceados && gcc -Wall -Wextra Ex.c -o par && ./par
```

### 7. Projeto Undo/Redo (`UndoRedo`)
```bash
cd EstruturaRecuperacaoDados_1/UndoRedo && gcc -Wall -Wextra Ex.c -o undoredo && ./undoredo
```
