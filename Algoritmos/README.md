# Algoritmos Fundamentais e Linguagem C 💻

Este módulo contém os exercícios práticos da disciplina de **Algoritmos e Programação em Linguagem C**, cobrindo desde a sintaxe básica até estruturas de dados compostas (`structs`) e modularização com funções.

---

## 📂 Estrutura das Aulas

```text
Algoritmos/
├── Aula2_Liguaguem_C/   # Entrada/saída de dados, variáveis e operadores básicos
├── Aula3_Condicionais/   # Estruturas de decisão (if, else, switch-case)
├── Aula4_Loops/          # Laços de repetição (for, while, do-while)
├── Aula5_Vetores/        # Arrays unidimensionais (vetores)
├── Aula6_Matrizes/       # Arrays bidimensionais (matrizes)
├── Aula7_Strings/        # Manipulação de cadeias de caracteres (strings e ctype.h)
├── Aula8_Ponteiros/      # Ponteiros, endereços de memória e ponteiros de ponteiros
├── Aula9_Funcoes/        # Modularização de código, passagem por valor e por referência
└── Aula10_Structs/       # Definição e uso de estruturas de dados compostas (structs)
```

## ⚡ Como Compilar e Executar (Copiar e Colar)

Para compilar e rodar qualquer exercício em C, utilize os comandos abaixo no seu terminal:

### 1. Aula 2 - Linguagem C Básica (`Aula2_Liguaguem_C`)
```bash
cd Algoritmos/Aula2_Liguaguem_C && gcc -Wall -Wextra Ex_1.c -o ex1 && ./ex1
```

## ⚙️ Compilação Genérica
Para compilar qualquer arquivo `.c` individual:
```bash
gcc -Wall -Wextra nome_do_arquivo.c -o programa && ./programa
```
